# RPDistill 全自动蒸馏流水线（F21）
状态：必选研发规范；E3.3b 已提交单次检索到候选语料快照调度（待 CI），完整自动蒸馏尚未实现。

## 一次性配置
学科/关键词（支持预设学科范围）、语种、发表日期、检索源、论文数量/采集周期、许可策略、教师模型与学生架构、语料数量门槛、GPU/内存/磁盘与时间/费用预算、训练参数、质量门槛、输出位置。提供合理默认值、预检与明确启动授权。未授权远程 API 或资源不自动调用。

## 自动流程
1. 按配置检索新论文；增量游标和 DOI/内容哈希去重，分页与限流。
2. 检查预定用途许可和合法全文可用性；未知/不允许的样本自动跳过。
3. 下载 PDF/XML/HTML，校验并缓存；自动重试、断点续传、记录来源。
4. 解析结构、分段、去噪、保护公式数字术语；自动隔离损坏或低质量文本。
5. 教师模型批量翻译；自动生成原文/译文对及模型版本、术语、质量信息。
6. 自动过滤漏译、数字错误、重复与低质量样本；可选人工复核不阻塞合格样本。按论文划分训练/验证/独立测试集，冻结测试集，生成版本化数据集。
7. 达到配置的数据门槛后自动启动真实学生训练与序列级蒸馏；增量训练以已验证学生检查点为起点。Logits/特征蒸馏在适配后可选。
8. 自动保存检查点、监控损失与资源、早停、异常恢复；硬件不足或超过预算暂停并报告。
9. 自动评测独立测试集，检查质量及性能回归。未达标不得发布；允许有限次数重试，失败保留旧版本。
10. 达标后自动量化、校验 RPTranslate 兼容性、导出带版本与哈希的候选模型包；量化后重新评测。正式替换生产模型由明确授权的发布策略决定。
11. 单次模式完成后退出；持续模式按照授权周期继续采集新论文和训练，达到预算、停止条件或用户取消即停止。

## 执行引擎
Python worker 与持久化 SQLite 任务状态；统一阶段接口、幂等键、检查点、依赖与状态转换、有限重试、失败隔离及可恢复队列。控制入口支持 CLI，GUI 后续接入。任何阶段不可伪造成功，必须有实际输出和状态证据。记录可审计运行日志、论文来源及许可证、数据集版本、教师学生版本、训练参数、评测报告和导出哈希；禁止日志泄露令牌。无需浏览器手工下载或逐段点击。

## 验收
- CPU CI 使用合成/自有或明确许可的小样本与模拟 HTTP 服务测试完整状态机、去重、断点恢复、许可过滤、低质量隔离、数据门槛触发、资源预算、失败停止及发布门槛。
- E3 真实公开论文在线检索、下载、解析与入库；E5/E6 真实权重更新和恢复；E9 真实 RPTranslate 导出及推理兼容。
- E12 必须有一次经授权的真实端到端运行，从检索合法论文到教师生成语料、真实训练、独立评测和候选模型导出，全程不逐阶段手工启动；报告时间、样本数、许可、硬件、训练和评测指标。持续模式另测试增量去重与停止条件。
- 仅有模拟测试或工作流 UI 不算端到端验收通过。

E3.3b 实现范围：CorpusPipeline 单次阶段串联、配置和阶段结果持久化、解析/翻译/快照恢复、候选数量门槛；采集阶段失败需新预算授权。不等于持续调度、真实训练、完整语义和权利验收或端到端发布。

E5a 已提交实际 CPU 序列级训练核心，单独 CLI 接入已明确复核的候选版本；尚未接自动触发，未保存优化器/RNG，不能无人值守训练到发布。E6 将继续持久训练状态与预算/恢复，正式自动训练必须有权利和质量授权及独立评测门槛。

E6a 单次训练段保存完整优化器/CPU RNG/游标，可从旧状态在同环境继续；软时间与单检查点预算、梯度累积。尚未实现自动周期保存、持久训练 worker、GPU/AMP 或自动正式数据质量授权；E6b 后续整合。

E6b1 训练段支持 CUDA/AMP 与 GPU 完整状态、显存软预算（真实 GPU 待本机），E6b2 继续将分段训练组织为持久自动周期保存 worker，正式训练权利与质量门槛仍必须满足。

E6b2 增加 training-* 持久队列，单次显式启动 worker 后自动训练分段、保存完整状态、继续至终态，支持 pause/cancel/resume/recover 与累计保守预留。尚非常驻计划任务，候选语料仍需明确权利/质量复核后才能 enqueue；尚未串联自动评测/量化/发布。

E7a 自动评测核心独立于训练 worker，需操作者准备人工参考和外部输出；自动分数不是模型发布许可。E7b 才接真实学生模型生成、基线对照与人工评测，后续接自动发布门槛。

E7b1 提供训练 checkpoint 到冻结参考评测报告的真实 CPU 接口，未接自动任务终态触发，尚不允许自动发布。正式质量、人工审核、实际资源性能及真实基线仍待 E7b2；报告 release_ready=false。

E7b2 候选质量验收支持词面泄漏审核、自动评分复算及人工匿名 A/B 流程，未真实进行人工盲测，也不自动发布。质量 gate 与人工声明绑定报告，仅作候选门槛，正式独立质量/许可/基线仍待验收。

E8a 提供独立压缩候选生成及 FP32 参考还原，尚未接自动质量回归/候选发布，E8b/E9 后续；所有候选 release_ready=false。

E8b 接入独立压缩候选质量回归与最小合格候选选择，绝对门槛不足/新增错误/泄漏时不选择，不授权发布；自动完整串联仍待 E9/E12。

E9a 仅显式候选诊断导出，不自动发布或自动认可质量、权利；正式质量门槛触发与 RPTranslate 独立自训练加载在 E9b，E12 整体自动串联。
